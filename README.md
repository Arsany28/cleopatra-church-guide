# ✝️ تطبيق كنيسة السيدة العذراء والبابا كيرلس عمود الدين - كليوباترا، الإسكندرية
### الدليل الإرشادي والتفاعلي الشامل (PWA + Google Sheets Database API)

---

## 🌟 مميزات التطبيق
1. **🗺️ خريطة تفاعلية ثلاثية الأبعاد:** تفاصيل الأدوار (الأرضي، الأول، البدروم)، المزارات، وأماكن الكنيسة مع تثبيت التفاصيل على الشاشة.
2. **📅 جدول المواعيد والقداسات:** تصفح القداسات ومدارس الأحد واجتماعات الشباب والأسرة.
3. **🛍️ متجر المكتبة الكنسية:** سلة مشتريات وحجز مباشر عبر WhatsApp لمسؤول المكتبة.
4. **🎙️ مركز الوسائط والمرافق:** بث مباشر يوتيوب، حجز الاستوديو، الكافتيريا، وصالة الألعاب.
5. **✝️ دليل الآباء الكهنة:** مواعيد الاعترافات مع إمكانية طلب موعد اعتراف سري.
6. **📱 تطبيق PWA يعمل بدون إنترنت (Offline):** إمكانية التثبيت على شاشة الموبايل الرئيسية (iOS / Android) مجاناً.
7. **☁️ قاعدة بيانات Google Sheets مجانية 100%:** عبر Google Apps Script بدون أي تكاليف سيرفرات.
8. **⚙️ لوحة تحكم مستقلة (`admin.html`):** لإدارة كافة البيانات وتعديلها بسهولة.

---

## 🚀 طريقة تشغيل Google Apps Script وربطه مع Google Sheets في دقيقة واحدة:

1. افتح [Google Sheets](https://sheets.new) وأنشئ شيت جديد.
2. من القائمة العلوية اضغط على **Extensions (الإضافات)** -> ثم اختر **Apps Script**.
3. احذف الكود الموجود والصق كود الملف `google_apps_script.js` الموجود في المشروع.
4. من القائمة العلوية اختر الدالة `setupDatabase` واضغط **Run (تشغيل)** لتهيئة الشيتات بالبيانات تلقائياً.
5. اضغط على الزر الأزرق **Deploy (نشر)** -> اختر **New deployment**.
6. اضغط على الترس ⚙️ واختر **Web app**:
   - **Description:** `Church Database API`
   - **Execute as:** `Me`
   - **Who has access:** `Anyone` (الجميع)
7. اضغط **Deploy** وانسخ رابط الـ **Web App URL**.
8. افتح صفحة الأدمن (`admin.html`)، والصق الرابط في خانة **Google Apps Script** واضغط **حفظ واختبار**!

## 🌐 طريقة الرفع على GitHub Pages (استضافة مجانية مدى الحياة):

1. أنشئ مستودعاً جديداً (New Repository) على [GitHub](https://github.com).
2. ارفع ملفات المشروع:
   ```bash
   git add .
   git commit -m "Initial church app release"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/<REPO_NAME>.git
   git push -u origin main
   ```
3. في صفحة المستودع على GitHub:
   - اذهب إلى **Settings (الإعدادات)** -> **Pages**.
   - تحت **Build and deployment** -> اختر Branch: `main` واضغط **Save**.
4. خلال 30 ثانية سيكون تطبيقك متاحاً على الإنترنت مجاناً على رابط:
   `https://<USERNAME>.github.io/<REPO_NAME>/`
   ورابط صفحة الأدمن:
   `https://<USERNAME>.github.io/<REPO_NAME>/admin.html`
